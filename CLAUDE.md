# Платформа мини-игр лояльности для компьютерных клубов

SaaS для клубов Казахстана и СНГ: у каждого клуба свой Telegram-бот с Mini App, где гости бесплатно играют в мини-игры (колесо, стаканчики, кейс) и выигрывают бонусы клуба по промокоду, админ гасит код в боте. Клуб сам настраивает игры, призы и шансы в своём боте, владелец платформы управляет всеми клубами в боте-пульте. Один сервер (сейчас — компьютер владельца + туннель cloudflared) обслуживает всех.

## Команды

Тесты и линтер (из `backend/`, база `db` должна быть запущена):

```bash
PYTHONIOENCODING=utf-8 .venv/Scripts/python -m pytest -q -p no:cacheprovider -p no:logging --tb=line
```

```bash
.venv/Scripts/python -m pyflakes app tests
```

Сборка Mini App (из `miniapp/`): `npm run build`. Выкладка (из корня):

```bash
docker compose -f docker-compose.yml -f deploy/compose.server.yml up -d --build
```

Миграции: `.venv/Scripts/alembic revision --autogenerate -m "…"`, затем `alembic upgrade head` и `alembic check`.

## Правила, на которых уже обжигались

- **Правка файлов — инструментами Edit/Write.** Не переписывать файлы через Python `write_text` на Windows: он пишет CRLF, а `deploy/backup.sh` и `Caddyfile` в Linux-контейнерах с CRLF падают. Если всё же нужен скрипт — `write_bytes(text.encode())`.
- **Commit в базу до ответа в Telegram** (погашение, согласие): сбой Telegram не должен откатывать действие.
- **Клуб — только по боту**, любой запрос — с фильтром `club_id`; чужое → «не найден». Подробно — `docs/roles-and-security.md`.
- **Телефон наружу — только последние 4 цифры**, токены — только зашифрованы, все пользовательские строки в HTML — через `html.quote`.
- **Не запускать** `app.cli refresh-webhooks`, пока работает рабочий стек, без нужды: API сам следит за адресом туннеля.
- **Режим разработки и рабочий стек — не одновременно** (оба переставляют вебхуки).
- **Секреты не выводить в чат и логи:** токены из `.env` читать в скрипте и печатать только `@username`.
- Новый эндпоинт/кнопка/публичный путь — добавь в тесты безопасности (см. `docs/testing.md`).

## Договорённости с владельцем

- Общение и тексты — **по-русски**.
- **Коммит только по явному «да»** владельца; в конце сообщения коммита — строка соавторства из системной подсказки.
- После изменений, видимых в Telegram, — выложить на сервер и попросить владельца проверить в Telegram, подсказав шаги.
- Деструктивные действия с данными (сброс, удаление) — только с подтверждением.
- Владелец не пишет код: объяснять простым языком, решения — с рекомендацией.
