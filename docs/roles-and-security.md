# Роли и безопасность

## Роли

| Роль | Как определяется | Где работает | Может |
| --- | --- | --- | --- |
| Гость | запись `guests` клуба | бот клуба, Mini App | играть, свои призы и правила |
| Админ | `club_staff.role = admin` | `/admin` в боте клуба | проверять и гасить коды, «Сегодня», «Гости» |
| Суперадмин клуба | `club_staff.role = owner`, один на клуб | `/admin` в боте клуба | всё, что админ + добавлять/убирать админов, «🎁 Призы и шансы» своего клуба |
| Владелец платформы | Telegram id в `PLATFORM_OWNER_IDS` | бот платформы + `/admin` в **любом** боте клуба | всё во всех клубах, назначает суперадминов |

Роль действует только в своём клубе (кроме владельца платформы). Код: `services/staff.py` (`role_in_club`, `can_manage_admins`, `can_edit_prizes`, `can_assign_superadmin`, `add_admin`, `assign_superadmin`, `remove_staff`). Права проверяются **на сервере при каждом действии**, кнопки — только удобство.

## Правила безопасности (не нарушать)

1. **Клуб — только по боту.** Никогда не брать `club_id` из запроса, тела или заголовка клиента.
2. **Любой запрос к данным клуба — с фильтром `club_id`.** Чужой промокод/гость → «не найден», без упоминания другого клуба.
3. **Mini App:** подпись `initData` токеном этого бота + свежесть `auth_date` (24 ч). id из `X-Bot-Id` вне BIGINT → 401.
4. **Вебхуки:** секрет бота в заголовке, сравнение `hmac.compare_digest`; неизвестный бот и неверный секрет — одинаковый 403. Секрет бота платформы выводится из `ENCRYPTION_KEY`.
5. **Секреты:** токены ботов в базе только зашифрованы (Fernet, ключ в `.env`); сообщение с токеном в пульте сразу удаляется; `.env` не в git.
6. **Телефоны:** во фронтенд не отдаются; в админ-панели и карточке гостя — только последние 4 цифры (`…1285`).
7. **Логи:** токены и телефоны вырезаются из итоговой строки (`logging_setup.py`, `<bot-token>`, `<phone>`).
8. **Случайность** — только `secrets`, только на сервере.
9. **Атомарность:** спин — блокировка гостя `FOR UPDATE`; погашение — условный `UPDATE … WHERE redeemed_at IS NULL`. **Изменения в базе фиксировать (commit) до ответа в Telegram**: сбой Telegram не должен откатывать погашение.
10. **Перебор кодов:** 10 «не найден» за 15 минут на админа → блок.
11. **Регистрация:** номер принимается только собственным контактом гостя (`contact.user_id == from_user.id`), один номер — один гость в клубе.
12. **HTML в сообщениях:** все пользовательские строки (названия, имена, тексты клуба) через `html.quote`.
13. **Наружу** через Caddy только `/app`, `/api`, `/tg`, `/health`, `/media`. `/docs` FastAPI не публикуется. Порты Docker — только `127.0.0.1`.
14. **Бот платформы** отвечает только владельцам; токен бота платформы нельзя подключить как бота клуба.

Каждый пункт закрыт тестами в `backend/tests/audit/test_security.py` и других — см. [testing.md](testing.md). Добавляешь эндпоинт или кнопку с правами — добавь его в матрицу тестов безопасности.
