# Боты: сценарии, кнопки, callback_data

Лимит Telegram на `callback_data` — 64 байта (проверяется тестом `test_b14`). Текст сообщения — 4096 символов, подпись к фото — 1024.

## Бот клуба — гость (`bots/handlers.py`)

```
/start ─► нет номера ─► «Поделиться номером» (reply-кнопка request_contact)
        └ контакт свой? ─► номер сохранён ─► правила + «Принимаю» (consent:accept)
        └ «Принимаю» ─► сообщение с правилами превращается в приветствие
зарегистрирован ─► приветствие (баннер клуба, если есть) + кнопки:
        «Играть» (Mini App, экран игр), «Мои призы» (Mini App &tab=prizes), «Правила» (guest:rules)
```

- **Гостю — без эмодзи** в текстах и на кнопках бота (проверяет `tests/audit/test_guest_texts.py`). Эмодзи приза (поле `emoji`) гостю не показывается; названия и тексты, которые написал сам клуб, выводятся как есть. В админ-панели и пульте эмодзи остаются.

- Регистрацию можно пройти и в Mini App: согласие — `POST /api/consent`, номер — `requestContact` → приходит боту обычным контактом.
- Длинные правила (не помещаются вместе с согласием) уходят отдельным сообщением.
- `fallback` на любой текст: зарегистрированному — кнопки, иначе — следующий шаг регистрации.

## Бот клуба — админ-панель (`bots/admin.py`)

Порядок роутеров (`bots/dispatcher.py`): редактор игр и призов → админ → гость. Фильтр `IsStaff` пропускает сотрудников клуба и владельцев платформы и передаёт `role`. Клавиатура `/admin`:

```
[ 📷 Сканировать QR                ]   всем (во всю ширину — главное действие у кассы)
[ 📋 Сегодня ] [ 🙋 Гости ]            всем
[ 🎮 Игры и призы ] [ 👥 Сотрудники ]  суперадмину и владельцу
[ 👑 Назначить суперадмина ]           только владельцу
```

Промокод можно просто отправить текстом — отдельной кнопки «Ввести код» нет. Кнопки старых клавиатур («⌨️ Ввести код», «🎮 Игры», «🎁 Призы и шансы», «➡️ Следующий промокод» в старых сообщениях) по-прежнему отвечают и присылают новую клавиатуру.

| Элемент | Значение |
| --- | --- |
| `/admin` | меню с ролью и reply-клавиатурой по правам |
| «📷 Сканировать QR» | Mini App `?scan=1` → сканер Telegram → код приходит как `web_app_data` |
| любой текст, похожий на код | проверка кода |
| `redeem:<CODE>` | погасить (commit → потом Telegram); после погашения кнопок нет |
| `admin:next` | только для старых сообщений: подсказка и клавиатура |
| «📋 Сегодня» | сводка за день по часовому поясу клуба (`services/stats.py`) |
| «🙋 Гости» | список (`g:list:<page>`), карточка (`g:card:<guest_id>:<page>`), поиск (`g:find` → состояние `GuestSearch.query`) |
| «🎮 Игры и призы» (суперадмин, владелец платформы; `bots/prize_editor.py`) | экран игр `pz:g`: включить/выключить `pz:on:<game>`, лимит `pz:cd:<game>:<секунды>` (1, 3, 7 дней), «🎁 Призы (N)» → список игры `pz:l:<game>` (`pz:list` — колесо) |
| список призов игры | карточка `pz:c:<id>`, «➕ Приз» `pz:a:<game>` (`pz:add` — колесо), «➕ Пустой» `pz:e:<game>` → одно сообщение «🎮 1 час игры 20» (для пустого можно только число), состояние `PrizeEdit.new_prize`; срок промокода — 14 дней, меняется в карточке; «⬅️ К играм» |
| карточка приза | название `pz:t:<id>`, шанс `pz:w:<id>`, срок `pz:d:<id>`, выключить `pz:o:<id>` → `pz:y:<id>`; состояния `PrizeEdit.title/weight/ttl` |
| «👥 Сотрудники» | список, `staff:rm:<telegram_id>` — убрать, `staff:add` — «➕ Добавить админа»: временная клавиатура с выбором пользователя (`request_users` id 1) и «⬅️ Отмена» |
| «👑 Назначить суперадмина» | выбор пользователя (`request_users` id 2) |

Обработчик поиска гостей объявлен **раньше** распознавания кода: в режиме поиска «ANDREW» — имя, а не код. Роутер редактора призов подключён раньше админского по той же причине; кнопка меню или команда выводит из ввода, `/cancel` отменяет.

## Бот платформы — пульт (`platform_bot/handlers.py`)

Только `PLATFORM_OWNER_IDS`; остальным — «служебный бот». Кнопки — `Nav(action, club_id, arg)`, упаковка `p:<action>:<club_id>:<arg>`. Перед всеми кнопками фильтр `ClubMissing` отвечает «Клуб не найден».

| action | Что делает | Состояние FSM |
| --- | --- | --- |
| `menu`, `clubs`, `club` | меню, список клубов, карточка клуба | — |
| `new` | новый клуб | `new_club_name` |
| `bot` | токен бота клуба (сообщение удаляется) | `bot_token` |
| `prizes`, `prize_add`, `prize_kind`, `prize_del` | призы: добавить (название → вес → тип), выключить | `prize_title`, `prize_weight`, `prize_kind` |
| `prize_card`, `prize_t`, `prize_w`, `prize_d` | карточка приза: название, шанс, срок промокода (логика — `services/prizes.py`) | `prize_edit` |
| `games`, `game_on`, `game_cd` | «🎮 Игры»: включение (arg — номер игры 0 колесо / 1 стаканчики / 2 кейс), лимит 60 с / 1 день / 7 дней (arg = секунды × 10 + номер); у `prizes` и `prize_add` arg — номер игры | — |
| `super` | суперадмин — выбор пользователя (request_users id 10) | `super_pick` |
| `sub`, `sub_add` | подписка: «оплачено до» или «не оплачено N дн.», +30/90/365 дней с суммой | `pay_amount` |
| `access_off` → `access_off_yes`, `access_on` | «⏸ Отключить доступ» (с подтверждением) / «▶️ Вернуть доступ»: `clubs.status`, сообщение суперадмину через бот клуба. `sub_cancel`, `sub_cancel_yes` — старые кнопки «Отменить подписку», теперь ведут сюда же | — |
| `billing` | «💳 К оплате»: не оплачено ⚠️, срок в ближайшие 3 дня ⏳, доступ отключён ⏸ | — |
| `rules` | правила (до 3500 символов) | `rules_text` |
| `qr` | QR для кассы файлом PNG | — |
| `limit`, `limit_set` | кнопки старых карточек «⏱ Лимит спинов» — открывают «🎮 Игры» | — |
| `brand…` | оформление: палитра, надпись, префикс, тексты, логотип/баннер, сброс | `brand_hub`, `brand_prefix`, `brand_text`, `brand_image` |
| `data`, `reset_guest`, `wipe` | сброс регистрации гостя (request_users id 11), очистка игровых данных (подтверждение названием клуба) | `reset_guest_pick`, `wipe_confirm` |

Состояния FSM хранятся в памяти: при перезапуске API незаконченный ввод начинается заново. `/cancel` — выход из любого ввода.

## Добавляешь кнопку или сценарий

1. Новое `callback_data` — проверь длину (≤ 64 байт) и добавь в тест `test_b14`.
2. Права — на сервере, через `services/staff.py`; не полагаться на скрытие кнопки.
3. Повторное нажатие той же кнопки даёт «message is not modified» — использовать `show()` в пульте или `suppress(TelegramAPIError)`.
4. Обнови этот файл.
